Phase 1 · AI discovery

Find the AI hiding in your code.

Lantern scans a repo and builds an AI bill of materials: the ML libraries, LLM API calls, model names and model files it uses. It also flags leaked keys and unsafe model formats, grades each finding by context to cut false positives, and maps everything to the OWASP Top 10 for LLM Apps and NIST AI RMF.

● Runs entirely in your browser. Nothing you scan is uploaded or stored.

Framework coverage where findings land

Findings

1 · Discover

Matches real imports, dependency files, LLM endpoints and model names, not plain words. A game about torches isn't PyTorch.

2 · Grade

Secrets are scored by randomness and nearby "example" or "demo" words, so sample keys drop to low or false positive.

3 · Inspect models

Pickle-based model files can run code when loaded. Lantern looks inside them for calls like os.system or eval.

4 · Map & export

Each finding is tagged with the OWASP LLM risk and NIST AI RMF function it supports, then exported as a CycloneDX AI-BOM.

An original learning project by Brian Temple. Regex and heuristics only, not a production security tool.
