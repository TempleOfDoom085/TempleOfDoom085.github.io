How This Works

This tool uses Web Bluetooth's advertisement scanning to read the raw signal strength (RSSI) broadcast by nearby BLE devices — no pairing required. Distance is a rough estimate from the signal's path loss and can vary a lot with obstacles, device orientation, and interference. Full passive multi-device scanning (requestLEScan) is only available in Chromium browsers, sometimes behind chrome://flags/#enable-experimental-web-platform-features. Where it's unavailable, this tool falls back to your browser's native device picker plus watchAdvertisements() for live tracking.
