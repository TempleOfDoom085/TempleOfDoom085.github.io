🔨 Brute Force
Tests every combination of characters. For an 8-character alphanumeric password, that's 218 trillion combinations. Always wins — just slowly.
🛡 Defense: Use long passwords (12+ chars). Every extra char multiplies the search space exponentially.
📖 Dictionary Attack
Uses a wordlist of known passwords. With 10 billion leaked passwords in the wild, if yours is common it's cracked in seconds. Fails on truly random strings.
🛡 Defense: Never use real words, names, or keyboard patterns. Use a password manager.
🌈 Rainbow Table
Precomputed hash→password lookup tables. Can crack an MD5 hash in milliseconds if the password is in the table. Defeated entirely by password salting.
🛡 Defense: Proper password storage always uses a random salt (bcrypt, Argon2) — this makes rainbow tables useless.
